# Guía para agentes en BlistArt Univers

- Edita `index.html`, `motor/` y `scripts/` como fuentes. `dist/` es generado por `npm run build`; no edites `dist/index.html` para cambios permanentes.
- Antes de describir una capacidad de Sara como activa o un recuerdo como real, compruébalo en BLIST o en datos autorizados. Distingue lo implementado de lo que está en pruebas o planificado.
- No publiques fragmentos de memoria privada, claves ni conversaciones en ejemplos de la página. Usa ejemplos generales cuando no haya datos públicos verificados.
- Conserva los cambios locales de otros agentes. Ejecuta `npm run build` y `git diff --check` tras cambios del sitio.
