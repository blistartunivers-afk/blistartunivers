## 📞 Reportar una vulnerabilidad

Si has descubierto una vulnerabilidad de seguridad en BLIST, por favor repórtala de forma privada.

### Cómo reportar

1. **No abras un issue público** con detalles de la vulnerabilidad.
2. Envía un correo privado al mantenedor del proyecto con:
   - Descripción de la vulnerabilidad
   - Pasos para reproducirla
   - Impacto potencial
   - Versión afectada
3. Espera confirmación antes de divulgar públicamente.

## 🛡️ Buenas prácticas de seguridad

- Nunca incluyas claves, tokens o secretos en el código.
- Usa variables de entorno para configuración sensible.
- Revisa las dependencias antes de agregarlas.
- Mantén el sistema actualizado.

## 📄 Licencia de divulgación

Este proyecto sigue los principios de divulgación responsable. Agradecemos a los investigadores de seguridad que reportan vulnerabilidades de forma ética.
